# Tooby 🎥

Tooby is a premium, offline-first video management and playback application built with Flutter. It brings a modern "YouTube-style" experience to your local video collection, focusing on organization, automated tagging, and seamless playback.

## ✨ Features

- **📂 Local Library Scanning**: Effortlessly scan device folders to index your video collection.
- **🏷️ Smart Tagging**: Organize your videos with a robust tagging system. Supports both automated folder-based tagging and manual editing.
- **🏠 Dynamic Home Feed**: Browse your collection through beautiful, auto-generated thumbnails.
- **🎬 Premium Playback**: High-performance video player powered by Chewie, with support for advanced controls and fullscreen mode.
- **🔍 Instant Search**: Find any video in your collection instantly by title or tags.
- **🌑 Dark-First UI**: A sleek, premium aesthetic designed for a modern viewing experience.

## 🛠️ Built With

### Core
- **Flutter & Dart**: The foundation of the cross-platform experience.
- **Riverpod**: Robust and scalable state management.

### Data & Services
- **SQLite (sqflite)**: Reliable local database for video metadata and tags.
- **Path Provider**: Secure local file system access.
- **Video Scanner Service**: Custom logic for efficient media indexing.

### Multimedia
- **Chewie & Video Player**: The industry standard for Flutter video playback.
- **Video Thumbnail**: Dynamic, frame-accurate thumbnail generation for local files.
- **Flutter Video Info**: Detailed metadata extraction (duration, resolution, etc.).
